# Tech Consultants Website - Editable Project

Files:
- index.html — homepage
- contact.html — loan enquiry page
- style.css — all styling and responsive layout
- script.js — review rotation, form validation, WhatsApp enquiry
- ORIGINAL_SITE_NOTES.txt — what was confirmed from the live site

## Run in VS Code
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. In `script.js`, set `whatsappNumber` to your business WhatsApp number with country code.
5. Edit text, partner names, images, and styling as needed.

This is a clean editable reconstruction based on the publicly visible website, not a byte-for-byte copy of server-side/private source.
